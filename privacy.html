隐私政策

更新于 2026 年 10 月 1 日（官网下载按钮改为直达安装包）

一句话版本：汲作把资料保存在你的电脑上。我们没有开发者服务器，也不收集使用数据；只有你触发某个功能时，相关请求才会直接发往原网站、你选择的服务商、Apple、Hugging Face 或 GitHub。

我们不收集任何数据

汲作没有账号系统、没有后端服务器、没有统计埋点、没有崩溃上报。软件运行时不会向开发者发送任何信息——包括你保存了什么链接、读了什么内容、用了什么模型。我们从技术上就无法知道有谁在使用这个软件。

你的资料保存在哪里

  • 链接、正文、转写稿、总结、翻译、脑图、评论、标签、合集和历史：保存在你电脑上的本地资料库里，不上传到汲作的服务器——因为我们没有服务器。
  • 本地导入的音频和视频：汲作只记住原文件的位置，不复制、不上传。
  • 模型服务的 API Key：保存在 macOS 钥匙串里，不写入资料库、日志或导出文件。
  • 备份：「设置 → 数据与备份」生成的备份文件保存在本机。

你可以把单条内容导出成 Markdown、纯文本、PDF、Word 或 JSON；也可以用「知识库同步」把资料导出成 Markdown，写进你自己选定的本机文件夹。这些都在本机完成。

软件什么时候联网

汲作只在下面这些由你触发、或由你开启的场景联网：

  • 抓取网页与评论：你粘贴链接、从浏览器扩展保存、批量保存博主作品或抓取评论时，访问对应的原网站。为显示正文图片、站点图标、视频封面，或播放、下载媒体，可能继续请求原网站或它使用的 CDN。
  • 使用模型功能：你运行总结、翻译、校对、脑图、标题整理或自动标签时，把完成该任务所需的文字发给你自己配置的模型服务商。若你开启了新内容自动处理，保存后会按你的设置自动发起同类请求。发送前界面会显示数据去向；服务商如何处理数据，适用它自己的隐私政策。
  • 在线语音转写：只有你选择在线转写时，音频片段才会发给你配置的转写服务。默认的本机转写不联网。
  • 下载 Apple 离线听写模型：首次使用本机语音识别、所需模型尚未安装时，App 会先征求确认，再由 macOS 向 Apple 下载模型。
  • 下载「按意思搜」的模型：只有你在设置里打开「按意思搜」时，App 才会下载一个约 96 MB 的开源模型（bge-small-zh-v1.5）：先连 Hugging Face，连不上再连国内镜像 hf-mirror.com，下载后核对校验值。之后搜索全部在本机计算，你的内容不会发给这两个网站。
  • 站点登录：你可以在 App 自带的登录窗口登录知乎、小红书、哔哩哔哩、抖音等站点，用于抓取登录后才能看的内容。登录页面直接连接对应站点。
  • 检查更新：在你允许后，向 GitHub 检查是否有新版本。这个请求不携带任何个人信息。

汲作不把这些请求转发给开发者，也不通过它们统计你用了什么功能。本官网不加载任何第三方脚本、字体或统计代码：页面只加载本站的样式表、图标和一个脚本文件。唯一的外部请求是首页向 GitHub 公开接口查询一次最新版本号和安装包地址，好让下载按钮直接给出适合你电脑的安装包；这个请求不带 Cookie，也不告诉 GitHub 你从哪个页面来，关掉 JavaScript 就不会发出。你可以打开浏览器开发者工具的「网络」面板自行核对。

浏览器扩展

扩展只在你点开它时读取当前标签页：显示这页的来源信息、查询这页在汲作里存过没有，并在你点保存后把正文和你勾选的评论交给本机的汲作。扩展和 App 之间走浏览器的本机通道，不经过互联网。

扩展不追踪浏览历史，不在后台读取页面，不读取整个浏览器的 Cookie 数据库。

AI 助手接入

如果你在「设置 → AI 助手接入」里连上 Claude Code、Codex 这类助手，它们可以通过本机的连接程序读写你的资料库，每一类权限都可以单独开关。连接程序在你的电脑上运行，不经过我们。助手读到的内容会不会发给它自己的服务商，取决于你用的助手，请查看它的隐私政策。

站点登录会话

登录 Cookie 保存在 App 为各站点分别建立的本机数据仓中，不会上传给开发者，也不会从你的浏览器导入。它只用于对应站点、由你触发的抓取。你可以在「设置 → 站点登录」查看状态并随时清除。

系统权限

  • 钥匙串：安全保存你的 API Key。
  • 屏幕录制（可选）：只在转写播放中的视频时需要，因为 macOS 把「录制系统音频」归在这个权限下。不用这项功能就不需要授予。
  • 备忘录、语音备忘录与文件访问（可选）：只在你导入这些内容时请求。

开源与可验证

汲作的源代码公开在 GitHub。以上每一条都可以在代码里核对，你也可以自己编译运行。

政策变更

如果本政策有变化，会在这个页面更新，并在版本更新说明里注明。我们不会引入与「资料留在本机」相悖的改动。

联系方式

对隐私有任何疑问，请在 GitHub Issues 提出。
