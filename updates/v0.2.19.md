# 汲作 v0.2.19

这一版都是修复，起因是把上一版新加的格式规则拿正常内容逐条撞了一遍，发现它们会误伤好内容——而且是悄悄地伤，正文缺字也不会报错。

- 修复：正文里的等号不再被当成高亮标记吃掉。上一版里 `if (a == b)` 会显示成 `if (a  b)`，`FOO==1 与 BAR==2` 会显示成 `FOO1 与 BAR2`。
- 修复：多层引用现在每层各自显示，不再整段按最深那层缩进。
- 修复：以年份开头的句子（例如「2026. 这一年……」）不再被当成编号 2026 的清单。
- 修复：紧挨着的两处删除线不再互相干扰导致文字消失。
- 修复：术语表里本身带星号的词条不再显示错乱。
- 修复：网页折叠块的标题如果是一整段说明文字，不再被当成小标题塞进大纲。
