# 汲作 v0.3.2

一轮集中打磨：翻译时阅读页不再闪，模型服务能接 Anthropic 协议、内置了 Magpie 本地网关，模型名全 App 统一写法。

## 阅读页

- **翻译时不再闪屏**：边看边翻时，内容没变的图片和折叠小三角沿用原来的那一份，文字只替换开始有变化的那一截；翻完那一刻不再出现新旧两页重叠的重影。
- 翻译进行中不再出现「目录 · N 节」整行把页面顶下去；「翻译完成」的提示浮在阅读区上方，不再挤压正文。
- 标题左边的折叠小三角不再先闪出一个系统默认的小文件图标。

## 模型服务

- **「其他服务商」可以选协议了**：OpenAI 兼容之外新增 Anthropic 协议，可以直连 Claude 官方接口或各家兼容 Messages 的服务，不必都绕一道转发。
- **新增「Magpie（本地）」服务商**：一键连本机的 Magpie 网关（127.0.0.1:3425），密钥可以不填，两种协议都能走；Magpie 没开时会明确告诉你，而不是报一句看不懂的网络错误。
- **模型带厂商图标和信息**：读取模型列表时，把服务商给的来源渠道、上下文长度、输出上限、能不能看图、思考档位都标在模型旁边。
- **模型名全 App 统一**：渠道只用来分组，列表里统一写「模型名 · 厂商」（例如「Claude Haiku 5.5 · Anthropic」）；翻译提示、生成记录这些没地方分组的位置，在后面用括号补上渠道。原始 ID 只在悬停提示和导出记录里出现。
- **「检测可用」不再一次测全**：编辑某个模型时只测它；在列表里勾了哪几个就测哪几个；行内和组头都能单独触发检测。本机服务（如 Magpie）不再被算作「付费」。

## 其他修正

- 设置页的出错提示和进度提示改成先讲发生了什么、再讲怎么办；详情页标题区去重；视频转写、抓取脚本和导出的一批细节修正。

## 升级须知

- 已有资料和生成结果都保留，不用重做。升级前会自动备份数据库。
- 浏览器扩展随 App 一起更新；如果弹窗还是旧样子，在浏览器的扩展管理页点一下刷新。
- 本版本仍是临时本机签名、未经苹果公证，第一次打开会被系统拦下：先双击一次，弹窗点「完成」；再打开「系统设置 → 隐私与安全性」，滚到最下面点「仍要打开」，确认一次即可，之后正常双击。
