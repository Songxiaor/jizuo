# 汲作 v0.3.4

这一版改的是导出。导出时可以选内容，默认是你正在看的那一页。点导出后不用再干等，保存框马上弹出。

## 导出

- 保存框下方有一排「内容」。只列出这一条实际有的：普通文章是总结、原文、译文、评论；转写过的是总结、配文、转写、校对稿、译文、评论。格式仍在菜单里选。
- 默认勾你正在看的那一页。看翻译时只勾译文，看原文、配文、转写或校对稿时只勾那一层，看总结时勾总结和原文。评论记着你上次的选择，第一次默认勾上。一项都不勾时不能导出。
- 导出成一个文件。顺序是总结、你正在看的那一层、其余勾选的内容、评论。只勾译文时评论用译文；原文和译文都勾时，评论原文在前，译文跟在每条下面。
- 只导出一层时，文件名加上这一层的名字，比如「（译文）」。选了多层就不加。
- 「复制全文」复制你正在看的那一层，不再把所有层都复制出去。「全部数据」不变。
- 点导出后，保存框立刻弹出。选好位置才开始生成，底部显示「正在生成 PDF…」或「正在生成 Word…」，做完显示「已导出」。
- 导出现在带上总结和译文。只有最新一次的结果，旧的不会再跟进去。
- 原文开头如果再写一遍文档标题，不再重复。各层里面的小标题各降一级，不和大标题抢一样的大小。
- X 帖里的引用按读得懂的引用块导出，不再出现机器用的标记。阿拉伯文段落按从右往左排。
- 没有缓存的图片不留空白，留下说明或链接。
