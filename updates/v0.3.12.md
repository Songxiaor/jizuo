# 汲作 v0.3.12

## 新增

- **一键录直播（抖音、小红书）**：在浏览器里打开直播间，点汲作扩展就能录，默认原画，也可以手动选清晰度。录完自动存进汲作，平台显示为「抖音直播 / 小红书直播」，带主播头像、作者和原直播间链接，并自动转写。
  - 需要先在电脑上装好 ffmpeg（例如用 Homebrew：`brew install ffmpeg`）；没装时会直接提示，不会录一半出错。
  - 磁盘空间不够时会提前停下并合并已录部分，不写坏文件。
- **浏览器代抓**：汲作自己抓不下来、但浏览器能打开的页面，会自动交给浏览器扩展在后台抓下来存进汲作，抓完自动关掉标签页。通过 AI 助手（MCP）送来的链接也走这条路，不用手动操作。
- **作者换了视频也认得出**：同一个链接，作者事后把视频换掉时，汲作会：
  - 只把「当前视频」的转写当作这条的转写，旧视频的转写保留但标明「旧视频的转写」；
  - 新视频自动排进本机转写（只转写，不重跑会花钱的总结）；
  - 在评论区、知识库笔记和 MCP 里提示「作者换过视频，较早的评论可能针对旧视频」；
  - 侧栏「待转写」、列表上的「已转写」、「待校对」和素材卡都按当前视频判断。
- **转写完会自动同步到知识库（Obsidian）**：以前只在存进新链接时同步，转写晚完成的笔记会一直缺稿；现在转写完成和每次启动都会补一次同步。

## 更顺手的界面

- **全局动效统一**：按钮按下、提示条出现与消失、数字变化、图标切换、弹窗、图片放大、小窗播放，全部收进一套节奏，快、轻、不抢戏。
- **开了系统「减弱动态效果」**：不再有位移和缩放，只保留淡入淡出或直接切换。
- **悬停有反馈**：阅读区页签、标签、按钮等悬停会轻微提亮；选中页签变粗时不再挤动旁边的页签。
- **提示不再顶动正文**：「总结已完成」「校对稿已保存」等提示浮在顶部，收起时正文不跳。
- **设置与导入**：设置页切分类更干脆；博主导入弹窗换链接后能重新加载；补译标题前会如实说明可能带上正文开头（最多 800 字）。

## 修好

- 通过 MCP 再送一次之前失败的链接，会真的重新抓，不再一直回「已在排队」。
- 批量抓取时汲作不会因为窗口在后台被系统「睡着」而卡住。
- 抖音页面加载慢时自动多等一次，不再直接判失败。
- 抓取失败的原因分得更清楚：超时、网站跳转到不允许的地址、小红书链接缺少必要参数（会提示换一条带完整参数的链接）分别报。
- 视频被容量上限挤掉后可以补下载；抖音长视频（详情数据很大时）不再下载失败。
- 同一篇里两个一模一样的流程图 / HTML，「看源码」各切各的；提示框展开后不会在公式排好时自己收起。
- 保存模型失败时不再清空刚粘贴的密钥；切换服务商预设时，上一家的密钥不会再带到新地址。
- 「…」菜单打开标签小窗时，等页面滚到位就立刻弹出，不再固定等一下。
- 目录跳到带公式、流程图的章节，落点更准。
- AI 正在写的时候展开的提示框，不会写着写着自己收起。
- 随手记、摘录、素材卡批量面板出现提示时，下方内容不再被推着晃一下。
- 笔记整理用掉的模型额度也计入用量合计。
- 浏览器代抓遇到错误页（比如小红书 404）会在几秒内说明原因，不再干等 90 秒超时。
