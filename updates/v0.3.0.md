# 汲作 v0.3.0

这是一次大版本更新：汲作有了自己的样子。每道加工都有一方印，转写稿像书一样排，校对改了哪些字用朱批标出来；还能按意思搜、把文件夹整批导入成合集、抓取评论，浏览器扩展也重做了。

## 新功能

- **按意思搜**：搜索结果后面多一组「意思相近」，不用记住原文用了哪个词。在设置里打开后，第一次会下载一个约 96 MB 的本机模型（连不上官方站会自动走国内镜像），之后全部在本机运行，内容不会上传。
- **合集**：侧栏新增「合集」，可以新建、改名、删除，右键「加入合集」，合集里可以拖动排序。把一个文件夹拖进来，会自动建一个同名合集。
- **本地导入不再复制文件**：音频和视频只记住原文件的位置，不占第二份空间；原文件挪了地方也能自动找回。导入时可以勾选「导入后转写」，右下角能看到进度，随时可以停。
- **自有 / 外部自动分开**：带下载来源的文件归到「外部」，其余归到「自有」，判断错了当场可以改。
- **评论抓取**：B 站、抖音、X、YouTube、知乎、小红书、Reddit 和论坛类网站，保存时可以带上评论（10 到 100 条，在设置里调），先勾选再保存。博主页批量保存时也能一起抓。
- **待转写**：侧栏「视图」里新增「待转写」，列出有音视频、还没有转写稿的内容。
- **转写后清理视频**：可以设成转写完就清理，或者保存满几天后清理，只删汲作自己下载的文件；需要时在阅读页点「重新下载视频」。

## 看得见的变化

- **工序印**：录、校、评、摘、译、图六道加工各有一方篆书印。还没做是虚线印位，做完就盖上。设置页也按这六道工序重新整理，打开「自动」就等于盖章。
- **朱批**：校对后的转写稿和机器原稿逐字比对，改动用朱色标在页边，可以随时切回原稿。
- **转写稿按书排**：时间码挂在页边，校对时自动加小标题，评论单独排在后面。
- **正文排版**：宋体、适合阅读的行宽、首段导语，列表和粗体都更整齐。
- **明式印章与新图标**：印文改用《说文》小篆；每个页面只在页头盖一方归属印（自有「作」、外部「汲」），文末落款写成「丙午年九月廿九日　记」。App 图标换成靛青色，顶上是一方「汲」字小印，浏览器扩展图标同步更换。
- **浏览器扩展重做**：弹窗先展示来源信息（标题、作者、字数、时长），打开时就能看出这页存过没有，已存过的可以直接「在汲作里打开」；保存后显示每道工序的进度。
- **侧栏按「自有 / 外部」分类**，再按来源、形式、标签细分；新增标签管理，可以改名、合并、删除。
- **加宽正文**开关（⌥⌘\），看宽表格和流程图更方便。

## 更快、更稳

- 列表和正文滑动更跟手，转写更快，后台占用更低。
- 转写校对分段更小、每段都核对，失败的段会自动补跑，仍失败会写明原因。

## 修掉的问题

- 抖音视频有时抓不到。
- 校对后的转写稿段落错位、开头被结尾内容覆盖。
- AI 助手连接断开时，App 可能直接退出。
- 打开旧条目时跳到了别的条目；栏宽被重置；设置窗口位置不对。
- 深色模式下部分按钮看不见、窄窗口下标题压住按钮等一批界面细节。

## 升级须知

- 已有资料和生成结果都保留，不用重做。升级前会自动备份数据库。
- 浏览器扩展随 App 一起更新；如果弹窗还是旧样子，在浏览器的扩展管理页点一下刷新。
- 本版本仍是临时本机签名、未经苹果公证，第一次打开会被系统拦下：先双击一次，弹窗点「完成」；再打开「系统设置 → 隐私与安全性」，滚到最下面点「仍要打开」，确认一次即可，之后正常双击。（网上常见的「右键选打开」在 macOS 15 之后已被苹果移除。）
