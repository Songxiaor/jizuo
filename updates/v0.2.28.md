# 汲作 v0.2.28 预览版

本次预览版集中整理界面：设置页更整齐，主题收成三套，字体和图标更统一。

- 设置页每张卡只有一个绿色主按钮，说明文字收进 ⓘ；模型编辑改成弹窗，一键「验证并保存」。
- 生成偏好改完即时生效，不再需要保存按钮；翻译、校对模型改完立即生效。
- 主题只剩浅色、深色、跟随系统；深色是浅色同一套配色的夜晚版。
- 界面字体改为系统字体；阅读字体多了「无衬线 / 宋体」一键切换。
- 侧栏图标统一单色线条，计数不再套灰底；来源平台默认只显示条数最多的 5 家，其余折叠。
- 三栏分成三档深浅，中间列表不再和侧栏黏在一起。
- 列表日期改为「1月1日」写法；抓取完成提示 3 秒后自动消失。

## 下载与使用

- Apple Silicon Mac 下载 Apple-Silicon.dmg；Intel Mac 下载 Intel.dmg。
- Universal.zip 同时包含两种架构。

## 预览版边界

本版本使用临时本机签名，尚未通过 Apple Developer ID 签名及公证。下载后 macOS 可能阻止首次打开；请仅在了解此限制的测试环境中使用。本预览版不替换稳定版自动更新。
