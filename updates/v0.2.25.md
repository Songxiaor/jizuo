# 汲作 v0.2.25 预览版

本次预览版让支持本地 MCP 的 Agent 连接汲作，并整合博主导入和阅读体验优化。

- 在「设置 → 连接与数据 → MCP 连接」开启服务，复制连接说明交给 Agent。
- Agent 可查询资料、按平台统计、提交链接，并在获得相应权限后请求转写或总结。
- 内容统计使用与 App 一致的分类；抓取与转写返回可区分的处理状态。
- 调整博主导入界面的空间分配，支持发现作品后选择保存。
- 改进批量操作、书签去重和播放区操作布局，保留已发布版的字幕与时间码能力。

## 下载与使用

- Apple Silicon Mac 下载 Apple-Silicon.dmg；Intel Mac 下载 Intel.dmg。
- Universal.zip 同时包含两种架构。
- MCP 程序已包含在 App 内，无须安装 Node、Python 或 Skill。App 需要保持运行；仅支持远程 URL 的云端 Agent 暂不适用。

## 预览版边界

本版本使用临时本机签名，尚未通过 Apple Developer ID 签名及公证。下载后 macOS 可能阻止首次打开；请仅在了解此限制的测试环境中使用。本预览版不替换稳定版自动更新。

平台登录、验证码、网络和模型服务仍影响抓取与转写；自动化测试不代表每个平台的真实端到端流程均已验证。
