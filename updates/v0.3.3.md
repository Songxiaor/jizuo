# 汲作 v0.3.3

这一版把阅读和侧栏里会闪、会跳、会顿的地方收了一遍。抓不到或没做成的时候，也更愿意把原因说清楚。

## 更顺滑

- 重新翻译、重新总结、重新转写时，正文不再先空一下，也不会整页闪回原文再慢慢变回来。中途停下重新翻译，会回到刚才那一份译文。
- 重新总结要等第一段写出来才换上，做完时也不会跳回旧的译文。重新转写同样留着旧稿，直到新稿写出第一段。
- 翻译进行中，标题那一行不再往下挪。推文译完不再多出一行大标题；普通文章仍会显示译文标题。
- 标题下面有没有标签，那一行都一样高，页面不再被撑一下。
- 点左侧「视图」时，列表不再整列跳一下。博主页里展开分组，这一组会带着内容出现。从列表进博主页再回来，侧栏按你正在看的那一行对齐。
- 「原文」和「翻译」整块字都能点到，不再只有笔画上才有反应。

## 更可靠

- 很短的那串数字帖子，如果作者或编号对不上，会拒绝保存并告诉你原因，不会存成别人的内容。
- 没登录时，抖音正文不再把和标题一模一样的那一段再写一遍。
- 在汲作里抓 YouTube 评论时，条数改用标题旁边的数字，不再拿页面上别的计数来显示。
- 保存没成功时，原因会换行写全，不再被裁成半句。
- 还没下载转写用的模型时，会告诉你需要先下载，不再说成你取消了。
- 转写、校对、脑图没做成时，那一行下面直接写原因。已经有译文再失败，仍显示失败、可以再试，旧译文留着。
- 排着队的翻译如果选过「忽略语言判断」，轮到它时还会照做，不会因为觉得语言已经匹配就悄悄跳过。
- 边看边翻时，评论不再混进正在翻的正文。翻译和总结各自提示自己的失败。
- 打开的这条已经有总结时，第一次使用的提示会自己消失。
- 从回收站恢复成功，提示写成「已恢复」，不再写成删除结果。
- 选中一条时，菜单栏「编辑」里的删除会先问是不是放进回收站。
- 导出时先收起菜单，再弹出保存位置。

## 更快

- 按上下方向键一条条看时，不再给每一行重新做一遍右键菜单。连着按的时候，详情只打开你停住的那一条。最长停顿从大约 1 秒降到大约 0.4 秒。
- 打开一条很长的转写时，分段和版式改到后台准备，点下去不用干等。
- 让助手做统计时改到后台算，不再挡着你操作。

## 已知问题

- 侧栏往下滚后，收起「来源」会跳一下。

已有资料和生成结果都保留，不用重做。
