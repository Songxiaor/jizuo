## 抖音视频抓不到（09:00 修复，扩展已部署，未提交）

- 现象：扩展抓抖音只得到「blob/MSE，只能在原浏览器会话观看」，评论正常。
- 原因：`fetchDouyinSessionDetailInMainWorld` 用 about:blank iframe 里干净的 fetch 请求详情接口，抖音现在要求 SDK 签名，未签名一律 403。页面自己的 fetch 会签名，但只给 `credentials: include` 的请求签（same-origin / 不写都返回 200 空体），`mode: same-origin` 会被 SDK 拒成 Failed to fetch。
- 修法：先用页面 fetch（include、redirect: error、无 mode），失败或空体再退回干净 fetch。安全规范测试改为只允许该文件出现一次 include 且必须 redirect: error；其他文件仍禁止。扩展 423 条通过；EGO 实测 /video/ 与 jingxuan?modal_id= 均拿到 douyinvod 直链。
