## 关键设计（长期决策，Brain CLI 本机未安装，待补录）

1. **本机素材统一用 `linkdigest-local://<source>/<id>` 作为条目地址。** 带 `://` 让 SQL 按 host 切出来源，侧栏分组、筛选、计数、卡片图库全部复用，不新增导航代码、不改数据库结构。只有 `CapturedDocument.Origin.localImport` 能建这种条目；转写稿（`localTranscription`）和画面字幕（`burnedInSubtitles`）可挂回它；浏览器与手动链接仍只认 http(s)。
2. **音频统一转 M4A、以 `.mp4` 后缀存入媒体库。** 媒体库、播放器、转写本来就按 MPEG-4 容器工作（B 站纯音轨同路），不用给每种后缀开新路。
3. **导入的图片走现有「按快照存本机图片」机制**（`GitHubREADMEImageCache.storeLocalImage`），文件名是引用串哈希，正文写 `![文件名](linkdigest-local://…)`，阅读页原位显示。
4. **备忘录走官方脚本接口（JXA / osascript），不读私有 NoteStore 数据库。** 代价是需要「自动化」授权，因此 `release_unit.py` 的 Info.plist 白名单与 `info_plist()` 同时加入 `NSAppleEventsUsageDescription`。
5. **素材类型与已使用都是普通标签**（`MaterialCatalog`），不另建表；「未使用」是新的列表范围 `.unused`。

## 已知边界

- 语音备忘录与备忘录读取依赖用户授权，Agent 无法代点；本机临时签名下，重新部署后授权可能需要重开（推断，未验证）。
- 语音备忘录读取 Apple 私有库 `CloudRecordings.db`，按列名兼容；读不到库时退回只列音频文件（标题变为日期）。
- 本机导入条目阅读页的「在浏览器中打开」按钮无动作（安全策略直接忽略），导出来源行显示内部地址。
- 「未使用」只统计资料（抓取与导入），不含「我的笔记」，与其它资料范围口径一致；快速记录存在笔记里，因此不进「未使用」。
- 快捷键 ⌃⌥N 若被其它 App 占用会静默失效，菜单入口始终可用。
