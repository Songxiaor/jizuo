# 汲作 v0.2.28

这一版把 0.2.25 起的预览能力收成正式版，GitHub Latest 与当前日用版本对齐。

上一正式版是 v0.2.24。中间预览版（MCP、博主批量抓取、界面精致化）都包含在这一版里。

## 从博主主页保存作品

- 博主目录显示姓名、头像和已保存作品，可集中浏览抖音、小红书、X 和 B 站。
- 在主页勾选作品后立即出现整批占位卡，逐条抓取、原位更新；支持取消、失败重试和中断后继续。
- 完成后不自动打开正文。中栏任务区只显示待处理项；全部成功后可关闭「已保存 N 条」，重启不会重复出现。

## 本地 MCP

- 在「设置 → 连接与数据 → MCP 连接」开启服务，复制连接说明交给支持本地 stdio 的 Agent。
- Agent 可查询资料、按平台统计、提交链接；转写和总结需分别授权。
- MCP 程序已包含在 App 内，无须安装 Node、Python 或 Skill。App 需要保持运行；只支持远程 URL 的云端 Agent 暂不适用。

## 界面

- 设置页每张卡只有一个绿色主按钮，说明文字收进 ⓘ；模型编辑改成弹窗，一键「验证并保存」。
- 主题只剩浅色、深色、跟随系统；界面字体改为系统字体，阅读字体可在「无衬线 / 宋体」之间切换。
- 抖音、B 站、公众号、X 的卡片统一为封面、两行标题、作者与日期、互动数据；竖版封面模糊底居中，视频带播放角标。
- 封面与博主头像下载一次即存本机，重启后不再重新加载。
- 添加模型时已存在的模型标「已添加」；服务商组头可删除这家的全部模型。

## 下载与使用

- Apple 芯片：`Jizuo-0.2.28-macOS-Apple-Silicon.dmg`
- Intel：`Jizuo-0.2.28-macOS-Intel.dmg`
- Universal.zip 同时包含两种架构，也是应用内更新使用的安装包。

已有资料和生成结果无需重做。

## 签名说明

本版本使用临时本机签名，尚未通过 Apple Developer ID 签名及公证。第一次打开可能被系统拦一次；到「系统设置 → 隐私与安全性」选择仍要打开即可。不需要关闭 Gatekeeper。
