# 汲作 v0.2.26 预览版：博主作品与批量抓取

这次更新围绕“从博主主页选择作品、批量保存、回到资料库阅读”完善完整流程。

## 新功能与体验改进

- 博主目录显示姓名、头像与已保存作品，可更新博主资料，集中浏览抖音、小红书、X 和 B 站内容。
- 主页选择作品后立即展示整批占位卡，逐条抓取、原位更新；完成后不自动打开正文。支持取消、失败重试与中断后手动继续。
- 中栏任务区只显示待处理任务的标题和状态。全部成功后显示可关闭的“已保存 N 条”，关闭后重启不会重复出现，不删除已保存文章。
- 四个平台统一使用 2.35:1 封面、两行标题、一行日期和底部单行互动数据。封面等比填满并裁切，列数随内容区宽度调整，常用 2–4 列，特别窄时 1 列。
- 公众号已保存文章新增左文右图横条，按可用宽度显示一列或两列，支持搜索、打开与返回。
- 标题与完整配文分开呈现：保留来源原标题，必要时为导航生成简短名称，正文不重复堆叠同一段配文，保留话题与图片。

## 抓取与阅读修复

- 抖音优先利用主页列表已返回的互动统计，只有缺失字段才进行有界补全；真实 0 与未获取的数据分开显示，避免用空结果覆盖有效值。
- 改进抖音作品封面的身份匹配、图文配文保存与播放状态判断，避免误用相邻作品信息。
- X 浏览器扩展与桌面端可交接博主候选作品，并校验、去重和保留选择。
- 改进 B 站封面与播放恢复、小红书元数据、阅读中的图片与段落呈现，以及资料侧栏刷新。

## 下载

Apple Silicon Mac 选择 Apple-Silicon.dmg，Intel Mac 选择 Intel.dmg；Universal.zip 包含两种架构。安装包包含配套 Chromium 扩展，可从 App 的浏览器支持设置查看安装指引。

## 预览版边界

- 本版延续临时本机签名，尚未完成 Apple Developer ID 签名和公证；macOS 可能阻止首次打开。此预览版不进入稳定版自动更新通道。
- 部分旧公众号／小红书文章仍缺少可用封面，显示明确占位；本次没有新增公众号主页批量抓取。
- 2.35:1 居中裁切会截去竖图上下部分；原图自身的白色区域仍可能显示。
- 平台登录、验证码、来源权限与网络状况仍会影响抓取，未获取的指标不冒充 0。
- 本轮未执行真实付费模型调用，也没有将缺少显式样本的语音、字幕和网络图片测试说成通过。
