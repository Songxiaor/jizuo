# 汲作 v0.2.28 预览版：界面精致化

这一版集中打磨界面：设置页收口、三套主题、统一字体与图标，平台卡片和阅读页按「缺省状态」逐一收拾。

## 界面

- 设置页每张卡只有一个绿色主按钮，说明文字收进 ⓘ；模型编辑改成弹窗，一键「验证并保存」；生成偏好改完即时生效。
- 主题只剩浅色、深色、跟随系统；界面字体改为系统字体，阅读字体多了「无衬线 / 宋体」一键切换。
- 侧栏图标统一单色线条，抖音、Substack 等图标与其它平台同一重量；「博主」组内新增「导入博主…」。
- 三栏底色分三档；列表日期统一「1月1日」写法；同一博主连续多条时不再每行重复作者名。

## 平台卡片与博主

- 抖音、B站、公众号、X 的卡片统一为「封面 / 两行标题 / 作者·日期 / 互动」，封面 16:9，竖版封面模糊底居中，视频一律带播放角标。
- 纯文字推文卡片标题用正文首句；摘要预览不再露出 Markdown 标记。
- 博主目录改横排小卡；博主作品页「抓取作品」为主按钮，卡片不重复博主名。
- 封面与博主头像下载一次即存本机，重启后不再重新加载。

## 阅读页

- 互动数据只保留一行，行尾标注「采集时快照」；没有切换器时「AI 处理」靠左。
- 抖音、B站作品视频在上、配文在下；短配文用界面字体，不再显示「目录」。
- 「整理文稿」不可用时，「AI 处理」菜单里会说明原因。

## 模型设置

- 添加模型时已存在的模型标「已添加」、不可重复勾选；批量保存后可直接测试连接，不再报「模型目的地已变化」。
- 服务商组头新增「删除这家的全部模型」。

## 下载与使用

- Apple Silicon Mac 下载 Apple-Silicon.dmg；Intel Mac 下载 Intel.dmg；Universal.zip 同时包含两种架构。

## 预览版边界

本版本使用临时本机签名，尚未通过 Apple Developer ID 签名及公证。下载后 macOS 可能阻止首次打开；请仅在了解此限制的测试环境中使用。本预览版不替换稳定版自动更新。
