# 抓取完整度测试表

2026-10-02。起因：Syc 反馈 arena.ai 一篇文章只存下很少的字，图和 GIF 都没有。目标：每个平台都分两种方式测——**浏览器扩展**和**在汲作里直接添加链接**——两边都要抓得完整；做不到一样的，把区别写进 App 让用户看到。

## 结论

- **两条路现在用同一套提取。** App「添加链接」改为在内置网页（Safari 内核）里打开链接，运行和扩展同一份打包脚本（`extract-page.js`，YouTube 用 `extract-youtube.js`）。通用网页两边的字数、图片数基本一致（见下表）。
- **区别只剩登录从哪来。** 扩展用浏览器里的登录；App 用「设置 → 站点登录」（新增知乎）。这一点写进了「添加链接」窗口，贴知乎、小红书、抖音链接且没登录时会提前提醒。
- **评论也一样存。** 「设置 → 收集 · 汲 → 评论」打开自动保存时，App 添加链接也顺带存前几条评论（原来只有扩展会存）；两边用同一份评论脚本。
- **阅读界面能播放 GIF 了**（真机截图核对：维基「旋转地球」、bubbletea 演示图都在动）。

## 怎么测的

- **扩展一列**：在 EGO 浏览器打开链接，把扩展正式注入的提取脚本原样跑在页面里（`scratchpad/probe/probe.mjs`）。抖音、YouTube 走专门脚本。
- **App 一列**：隔离的测试实例（独立资料库，不碰正式数据），经 App 自带的 MCP 通道提交链接，走和用户贴链接完全相同的流程。
- **页面一列**：页面上正文段落的字数和大图数，是粗略参照（不含表格、推荐栏），抓到的比它多不代表多抓了杂项。
- 格式：字数/图片数。✅ 完整 · ⚠️ 有缺口（备注说明原因）· — 不适用。

## 这次修了什么

1. 挑错正文：页面上的 `<article>` 全是推荐卡片时改取 `<main>`；Safari 内核里流式渲染没收尾时从隐藏块取正文。
2. App 原来删掉所有图片：直读路径也保留图片（取懒加载真地址、补全相对地址）。
3. GIF 不会动：阅读页认出动图后用会播放的控件显示（「减少动态效果」打开时保持静止）。
4. 杂项进正文：头像、图标、1×1 占位图、播放器按钮文字、Medium 图片按钮文字、空标题「#」、空加粗「****」、加载不出的图留下的「图像」。
5. 排版：加粗后的空格被吞、两段强调粘成「*****」、表格里的图把表格拦腰截断。
6. 拦截页当正文存：知乎验证页 / 登录页、小红书 404、Cloudflare 拦截页、Medium 500 错误页都会被拦下并说明原因。
7. YouTube：App 能拿到字幕（不经 `eval`、不伪装 Chrome 身份）；字幕不再存两遍。
8. GitHub：笔记本转成可读文章；代码文件放进代码块、标题用文件名。
9. 公众号：App 改用扩展同款提取，格式和扩展一致。
10. 头条在 App 里超时：页面开始显示后最多再等 15 秒就提取。
11. Medium 会员文章：两边都标成「仅可见部分」，阅读页提示可能不是全文。
12. App 内置网页的安全：本机、局域网、内网地址一律不访问（AI 助手经 MCP 添加链接也一样）。
13. 存原文（Syc 10-02 定）：X 开着自动翻译时，扩展先把帖子和回复切回原文再存，存完切回；Substack 阅读器的平台翻译没有开关，弹窗提醒改用「添加链接」。
14. GitHub：扩展也直接读原始文件（代码进代码块、Markdown 原样）；App 的项目首页改从渲染页面取 README，和扩展一致。
15. 导航热区图、链回首页的站名图不进正文（两条路同一规则）。
16. 知乎登录后的「划线评论」：句子不再被当评论区删掉，段落里的行内标签不再补空格（两条路同一规则）。
17. App 添加链接按评论设置自动存评论，和扩展同一套规则（平台单独设的条数优先，设成不抓就不存）；博主批量保存仍看它自己的「同时抓取评论」。
18. App 的隐藏网页：系统把它当「看不见」，页面动画帧和「滚到眼前」通知都不触发，YouTube 评论区只渲染 2 条。汲作只在自己的隐藏网页里换成计时器驱动的替身。
19. YouTube 在 App 里：读字幕时限放宽到 55 秒；页面还没渲染好时隔 3 秒再取一次，不直接退回直读。
20. 读评论的隐藏网页和抓正文一样，页面开始显示后最多再等 15 秒，不再等「完全加载完毕」等到超时。
21. 论坛评论作者：Discourse（linux.do）每楼的头像链接排在名字前面，作者全成了「未知用户」，现在取第一个有字的。

## 还没解决 / 需要 Syc

- **要你登录一次**：知乎、小红书、抖音在 App 里抓之前，到「设置 → 站点登录」登录（知乎是这次新加的）。没登录时「添加链接」会提前提醒。10-02 已登录，知乎、抖音两行重测通过。
- **EGO 里小红书没登录**：直接打开笔记链接会跳登录页（从首页点开可以看），扩展用的是浏览器自己的登录。登录后再对照两边评论能不能加载第一批之后的部分。
- **网站本身的限制**：Medium 会员文章没登录只有开头（已标成「仅可见部分」）；Substack 阅读器的平台翻译没有切回原文的开关（弹窗提醒改用「添加链接」）。
- **小问题**：GitHub README 里的 SVG 徽章显示成文字（汲作的图片缓存不收 SVG）。
- **更正**：之前说「库里英文 X 帖大概率存的是译文」不准确——9 月 30 日存的那条正文就是英文原文，列表里的中文标题是汲作的「标题翻译」；X 从什么时候开始对你自动翻译不确定。
- **测试里两条老问题**：`ManualLinkViewModelTests` 里「排队中取消」那条用改动前的代码也会卡住，「导入博主主页」几条在测试进程里会崩（`NSApp` 为空），与本次改动无关。
