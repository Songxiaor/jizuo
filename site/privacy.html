隐私政策

更新于 2026 年 8 月 18 日

一句话版本：你的数据全部留在你自己的电脑上。我们没有服务器，收不到、也不想收你的任何数据。

我们不收集任何数据

汲作没有账号系统、没有后端服务器、没有统计埋点、没有崩溃上报。软件运行时不会向开发者发送任何信息——包括你保存了什么链接、读了什么文章、用了什么模型。我们从技术上就无法知道有谁在使用这个软件。

你的数据保存在哪里

  • 链接、正文、总结、翻译、脑图、标签和历史记录：全部保存在你电脑上的本地数据库里，不上传到任何地方。
  • AI 服务的 API Key：保存在 macOS 钥匙串里，不写入数据库、日志或导出文件。
  • 所有内容随时可以导出为 Markdown、纯文本、PDF、Word 或 JSON 带走，也可以随数据库文件一并删除。

软件什么时候联网

汲作只在下面几种情况发出网络请求，每一种都由你主动触发或明确允许：

  • 抓取网页：你粘贴链接或从浏览器发送页面时，访问那个网页本身。
  • 总结与翻译：你点击总结或翻译时，把这篇正文发送给你自己配置的 AI 服务商（发送前界面会明确显示发给谁）。这部分数据如何处理，适用该服务商自己的隐私政策。
  • 检查更新：在你允许后，定期向 GitHub 检查是否有新版本。这个请求不携带任何个人信息。

除此之外没有任何网络活动。本官网同样不加载任何第三方脚本、字体或统计代码。

浏览器扩展

  • 扩展只在你主动点击时读取当前标签页的正文，发送给本机的汲作应用；两者之间通过浏览器的本地通道通信，不经过互联网。
  • 扩展不追踪浏览历史，不在后台读取页面，不读取整个浏览器的 Cookie 数据库。

系统权限

  • 钥匙串：用于安全保存你的 API Key。
  • 屏幕录制（可选）：仅在你使用视频转写时需要——macOS 把「录制系统音频」归在这个权限下。不用转写就不需要授予。

开源与可验证

汲作的源代码公开在 GitHub。以上每一条承诺都可以在代码里验证，你也可以自行编译运行。

政策变更

如果本政策发生变化，会在这个页面更新，并在版本更新说明中注明。我们不会引入与"数据留在本机"相悖的改动。

联系方式

对隐私有任何疑问，请在 GitHub Issues 提出。
