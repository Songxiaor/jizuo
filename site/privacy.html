隐私政策

更新于 2026 年 9 月 3 日

一句话版本：汲作默认把资料保存在你的电脑上。我们没有开发者服务器，也不收集使用数据；只有你触发抓取、模型、媒体或更新功能时，相关请求才会发往原网站、你选择的服务商或 GitHub。

我们不收集任何数据

汲作没有账号系统、没有后端服务器、没有统计埋点、没有崩溃上报。软件运行时不会向开发者发送任何信息——包括你保存了什么链接、读了什么文章、用了什么模型。我们从技术上就无法知道有谁在使用这个软件。

你的数据保存在哪里

  • 链接、正文、总结、翻译、脑图、标签和历史记录：默认保存在你电脑上的本地数据库里，不上传到汲作的服务器——因为我们没有服务器。
  • AI 服务的 API Key：保存在 macOS 钥匙串里，不写入数据库、日志或导出文件。
  • 所有内容随时可以导出为 Markdown、纯文本、PDF、Word 或 JSON 带走，也可以随数据库文件一并删除。

软件什么时候联网

汲作只在下面这些用户可控的场景联网：

  • 抓取网页：你粘贴链接或从浏览器发送页面时，访问原网站。为显示正文图片、站点图标、视频封面、临时播放或保存媒体，可能继续请求原网站或它使用的 CDN。
  • 使用 AI 功能：你运行总结、翻译、脑图、标题整理、转写校对或自动标签等功能时，把完成该任务所需的正文发送给你自己配置的 AI 服务商。若你开启了新内容自动处理，保存后会按你的设置自动发起同类请求。发送前界面会显示数据去向；服务商如何处理数据，适用它自己的隐私政策。
  • 在线语音转写：只有你选择在线转写时，音频片段才会发给你配置的转写服务。本机 Apple 语音识别不走这条网络链路。
  • 站点登录：你可以在 App 自带的登录窗口登录哔哩哔哩、小红书或抖音，用于手动抓取登录后正文或恢复临时播放。登录页面直接连接对应站点。
  • 检查更新：在你允许后，定期向 GitHub 检查是否有新版本。这个请求不携带任何个人信息。

汲作不把这些请求转发给开发者，也不通过它们统计你使用了什么功能。本官网不加载任何第三方脚本、字体或统计代码——这两个页面除了自己的样式表和图标之外不发出任何请求，你可以打开浏览器的开发者工具「网络」面板自行核对。

浏览器扩展

  • 扩展只在你主动点击时读取当前标签页的正文，发送给本机的汲作应用；两者之间通过浏览器的本地通道通信，不经过互联网。
  • 扩展不追踪浏览历史，不在后台读取页面，不读取整个浏览器的 Cookie 数据库。

站点登录会话

  • 登录 Cookie 保存在 App 为各站点分别建立的本机 WebView 数据仓中，不会上传给开发者，也不会从你的浏览器 Profile 导入。
  • Cookie 只用于对应站点的用户触发流程。你可以在“设置 → 站点登录”中查看状态并随时清除。

系统权限

  • 钥匙串：用于安全保存你的 API Key。
  • 屏幕录制（可选）：仅在你使用视频转写时需要——macOS 把「录制系统音频」归在这个权限下。不用转写就不需要授予。

开源与可验证

汲作的源代码公开在 GitHub。以上每一条承诺都可以在代码里验证，你也可以自行编译运行。

政策变更

如果本政策发生变化，会在这个页面更新，并在版本更新说明中注明。我们不会引入与"数据留在本机"相悖的改动。

联系方式

对隐私有任何疑问，请在 GitHub Issues 提出。
