# 阅读方法# 信息管理# AI 工具

它做什么

一条链接进去，一份能带走的东西出来。

本地抓取

抓取正文

粘贴链接，或从浏览器一键发送当前页面。只取正文，不要广告和导航。

总结与翻译

用你自己配置的 AI 服务处理。长文自动拆片并行翻译，不必干等。

生成脑图

把总结变成结构图。可换主题、可编辑、可导出，不再消耗额度。

视频转写

B 站、抖音、YouTube 等站点的音频转成文字，再走同一套总结流程。

标签、检索、导出

自动打标签，搜索覆盖标题、正文和总结。Markdown、PDF、Word、JSON，脑图另可存 SVG。

安装

第一次打开会被系统拦一次，这是正常的——第 1 步专门讲怎么放行。

1

让系统允许打开

这个软件还没有购买苹果开发者证书，所以 macOS 会拦一次。它不是病毒，但需要你手动放行一次：

  1. 双击应用，弹出「无法打开，因为无法验证开发者」——点「完成」
  2. 打开 系统设置 › 隐私与安全性，滚到最下面的「安全性」区域
  3. 看到「已阻止使用 汲作」，点右边的 仍要打开
  4. 再确认一次「打开」。以后正常双击即可，不用再放行。
网上很多教程说「右键点图标再选打开」——那个方法在 macOS 15 之后已被苹果移除。本软件要求 macOS 15 以上，请按上面的系统设置流程操作。
2

安装浏览器扩展可跳过

只用粘贴链接的话，这步可以不做。装了扩展才能把需要登录才看得到的页面发给应用。

  1. 打开 Chrome，地址栏输入 chrome://extensions
  2. 打开右上角的「开发者模式」开关
  3. 点「加载已解压的扩展程序」，选择应用「浏览器支持」页面指出的文件夹
扩展尚未上架 Chrome 应用商店，只能用开发者模式安装。Chrome 每次启动会提示「请停用以开发者模式运行的扩展程序」，点「取消」即可，不影响使用。
3

填入你自己的 AI 密钥

本软件不含任何 AI 额度，也不代收费用。你在服务商那边注册充值，用多少和服务商结算。

  1. 打开应用的 设置 › 模型与服务
  2. 选一个服务商或填自定义地址，粘贴 API Key
  3. 点「测试连接」确认可用，保存
密钥存在 macOS 钥匙串里，不会写进数据库、日志或导出文件。

常见问题

为什么提示「无法验证开发者」？安全吗？

因为还没有购买苹果开发者证书（年费 99 美元）为软件签名。macOS 对所有未签名软件都会这样提示，与软件本身是否安全无关。源代码公开，你可以自己查看或自行编译。

我的数据会被上传吗？

抓取的网页、总结、翻译和历史记录全部保存在你自己的电脑上。只有点击总结或翻译时，正文才会发送给你自己配置的那家 AI 服务商——发送前应用会明确告诉你发给谁。除此之外没有任何服务器。

为什么转写视频要屏幕录制权限？

转写需要采集正在播放的声音，而 macOS 把「录制系统音频」归在屏幕录制权限里。弹窗措辞是苹果定的，无法改成「录制音频」。不做视频转写就不需要授予这个权限。

支持 Intel 芯片的 Mac 吗？

支持。Apple 芯片和 Intel 芯片各有一份安装包，选对应的即可。系统需要 macOS 15 或更新版本。

支持 Windows 吗？

暂不支持，目前只有 macOS 版本。

要花钱吗？

软件本身免费开源。你只需向自己选择的 AI 服务商付费，按实际用量计费，与本软件无关。
