安装

下载、放行、填一个 API Key，三步。第一次打开会被 macOS 拦一次，这是正常的。

先选一个安装包

不确定自己是什么芯片？点屏幕左上角的 → 关于本机，那一行写着「芯片」的就是。

  • Apple 芯片 M1 / M2 / M3 / M4 等，2020 年后的 Mac 基本都是 …macOS-Apple-Silicon.dmg
  • Intel 芯片 更早的 Mac，「关于本机」里写的是 Intel Core …macOS-Intel.dmg
  • 都不确定 / 要一个通用包 两种芯片通用，体积大一些 …macOS-Universal.zip

1 让系统允许打开 所有人都要做一次

当前版本还没有苹果开发者签名和公证，所以 macOS 无法验证开发者身份并会拦截。请只从本页指向的 GitHub 官方发布页下载；下面是当前版本的系统放行步骤：

  1. 双击应用，弹出「无法打开，因为无法验证开发者」——点「完成」
  2. 打开 系统设置 › 隐私与安全性，滚到最下面的「安全性」区域
  3. 看到「已阻止使用 汲作」，点右边的 仍要打开
  4. 再确认一次「打开」。以后正常双击即可，不用再放行。
网上很多教程说「右键点图标再选打开」——那个方法在 macOS 15 之后已被苹果移除。本软件要求 macOS 15 以上，请按上面的系统设置流程操作。
2 填入你自己的 AI 密钥 要用总结和翻译就得填

本软件不含任何 AI 额度，也不代收费用。你在服务商那边注册充值，用多少和服务商结算。

  1. 打开应用的 设置 › 模型与识别
  2. 选一个服务商或填自定义地址，粘贴 API Key
  3. 点「测试连接」确认可用，保存
密钥存在 macOS 钥匙串里，不会写进数据库、日志或导出文件。
3 安装浏览器扩展 可跳过

只用粘贴链接的话，这步可以不做。装了扩展才能把需要登录才看得到的页面发给应用。

  1. 打开 Chrome，地址栏输入 chrome://extensions
  2. 打开右上角的「开发者模式」开关
  3. 点「加载已解压的扩展程序」，选择应用「浏览器支持」页面指出的文件夹
扩展尚未上架 Chrome 应用商店，只能用开发者模式安装。Chrome 每次启动会提示「请停用以开发者模式运行的扩展程序」，点「取消」即可，不影响使用。

常见问题

为什么提示「无法验证开发者」？安全吗？

因为当前版本还没有使用 Developer ID 签名并提交苹果公证。这个提示只能说明系统无法验证开发者身份，不能单独证明软件安全或不安全。请只从官方发布页下载；源代码公开，你也可以自行查看或编译。

我的数据会被上传吗？

链接、正文、结果和历史默认保存在你的电脑上，我们没有开发者服务器。你触发抓取、模型、在线转写、媒体或更新功能时，App 会直接连接原网站、你选择的服务商或 GitHub；完整范围见隐私政策。

为什么转写视频要屏幕录制权限？

转写需要采集正在播放的声音，而 macOS 把「录制系统音频」归在屏幕录制权限里。弹窗措辞是苹果定的，无法改成「录制音频」。不做视频转写就不需要授予这个权限。

支持 Intel 芯片的 Mac 吗？

支持。发布页同时提供 Apple 芯片版、Intel 版和两者通用的 Universal 版，按上面的对照表选一个即可。系统需要 macOS 15 或更新版本。

支持 Windows 吗？

暂不支持，目前只有 macOS 版本。

要花钱吗？

软件本身免费开源。你只需向自己选择的 AI 服务商付费，按实际用量计费，与本软件无关。

数据存在哪？换电脑怎么办？

存在本机的数据库文件里。当前版本支持把单条记录导出为 Markdown、纯文本、PDF、Word 或 JSON，暂不提供整库导出和一键迁移。没有账号系统，所以也没有「同步」这回事。
