两方印

自己写的，还是汲来的

书画上，作者落款盖名章，收藏家在藏品上盖鉴藏印。汲作也只用两方印分家：每一条内容打开时，页头都盖着其中一方。

作自有 · 白文名章

你自己写下、录下的东西。备忘录和语音备忘录可以导进来，本地文件拖进来就归到这里。

  • 笔记
  • 备忘录
  • 语音备忘录
  • 自己的文件

汲外部 · 朱文鉴藏印

从网上收来的：文章、视频、帖子、别人的博主页。保存时就记下出处和作者，落款写明从哪里汲来。

  • 网页文章
  • 视频与播客
  • 社交帖子
  • 下载来的文件

分错了也没关系：右键就能改成另一边。

六道工序

一道加工，一方印

收进来的东西要读完，得经过几道手。每道工序有一方篆书印：还没做是虚线印位，做完就盖上。哪道自动做、哪道手动点，在设置里一眼看清。

录第一道 · 转写

视频和音频在本机听写成文字，时间码挂在页边，点一下跳回那一秒。不用把声音传给任何人。

校第二道 · 校对

模型逐段校对听写稿，补标点、改错字、加小标题。改了哪些字用朱批标在页边，随时切回原稿。

评第三道 · 评论

保存时带上评论区，十条到一百条，先勾选要哪几条。有时候评论比正文更值得留。

摘第四道 · 总结

用你自己的模型写总结：核心结论在前，证据和细节在后。长文拆段并行，不必干等。

译第五道 · 翻译

外文逐段译成中文，和原文对照着读。是中文的内容，这一道自动跳过。

图第六道 · 脑图

把总结变成一张结构图，可以改、可以换样式，导出成 SVG 带走，不再额外消耗额度。

虚线是印位，这道还没做 盖好的章，这道做完了

朱批

听错的字，用朱笔改在页边

本机听写快，但同音字常错。校对后，汲作把校对稿和原稿逐字比对：正文只留一道淡淡的朱线，改了什么写在页边。

按意思搜

记不清原文怎么说的也能找到：关键词结果后面附一组「意思相近」。模型在本机运行，第一次打开时下载一次（约 96 MB）。

合集

把相关的内容收成一册，拖动排序。整个文件夹拖进来，会自动建一个同名合集。

本地导入

音频、视频只记住原文件的位置，不复制第二份；文件挪了地方也能找回。导入时可以顺手排队转写。

浏览器扩展

在网页上点一下就保存。打开弹窗就知道这页存过没有，存过的直接跳到汲作里那一条。

博主与批量

添加一位博主，列出全部作品，挑几条一起保存，评论也能一起带上。

AI 助手接入

让 Claude Code、Codex 这类助手直接读写你的资料库。连接程序随 App 装好，权限逐项开关。

知识库同步

把资料导出成 Markdown，放进你自己的知识库文件夹，在后台安静进行。

导出与备份

单条导出成 Markdown、纯文本、PDF、Word 或 JSON；整个资料库可以随时备份一份、换回某一份。

安装

下载、放行、填一个模型服务

第一次打开会被 macOS 拦一次，这是正常的：汲作目前还没有苹果开发者签名和公证。

第一步

选一个安装包

不确定自己是什么芯片？点屏幕左上角的苹果标志 → 关于本机，看「芯片」那一行。

Apple 芯片M1、M2、M3、M4 等，2020 年后的 Mac 基本都是…macOS-Apple-Silicon.dmg
Intel 芯片更早的 Mac，「关于本机」里写着 Intel…macOS-Intel.dmg
都不确定两种芯片通用，体积大一些…macOS-Universal.zip
前往下载页

第二步

让系统允许打开每人一次

  1. 双击汲作，弹出「无法验证开发者」，点完成。
  2. 打开 系统设置 → 隐私与安全性，滚到最下面的「安全性」。
  3. 看到「已阻止使用汲作」，点右边的仍要打开，再确认一次。以后正常双击即可。

网上常见的「右键点图标选打开」在 macOS 15 之后已被苹果移除，请按上面的系统设置操作。只从本页指向的 GitHub 发布页下载。

第三步

填入你自己的模型服务要用总结、翻译时

  1. 打开 设置 → 模型服务，选一个服务商，或填任一 OpenAI 兼容服务的地址。
  2. 粘贴 API Key，点「测试连接」，保存。

只用抓取和本机转写的话，这一步可以先跳过。

第四步

装上浏览器扩展可选

  1. 在汲作里打开 设置 → 浏览器支持，点「打开扩展文件夹」。
  2. 在 Chrome、Edge 或 Brave 里打开扩展管理页，打开「开发者模式」。
  3. 点「加载已解压的扩展程序」，选中刚才那个文件夹，回到汲作完成连接。

扩展还没上架应用商店，只能这样安装。以后扩展随 App 一起更新，在扩展管理页点一下刷新就好。

常见问题

先回答几个常被问到的

为什么提示「无法验证开发者」？安全吗？

因为当前版本还没有用 Developer ID 签名、也没有提交苹果公证。这个提示只说明系统无法验证开发者身份，不能单独证明软件安全或不安全。请只从官方发布页下载；源代码公开，你也可以自己查看或编译。

我的资料会被上传吗？

链接、正文、生成结果和历史默认保存在你的电脑上，我们没有开发者服务器。只有你触发抓取、模型、在线转写、模型下载或检查更新时，App 才会直接连接原网站、你选的服务商、Hugging Face 或 GitHub。完整范围见隐私政策。

要花钱吗？

软件本身免费开源。用到总结、翻译、校对时，你向自己选的模型服务商付费，按实际用量计，与汲作无关。抓取、本机转写和按意思搜都不花钱。

为什么转写视频要屏幕录制权限？

转写播放中的视频需要采集系统声音，而 macOS 把「录制系统音频」归在屏幕录制权限里。弹窗措辞是苹果定的。不做视频转写就不需要这个权限。

支持 Intel 芯片和 Windows 吗？

Intel 芯片的 Mac 支持，发布页有 Intel 专用包和通用包，系统需要 macOS 15 或更新。Windows 暂不支持。

数据存在哪？换电脑怎么办？

存在本机的资料库文件里。「设置 → 数据与备份」可以随时存一份备份、换回某一份；单条内容能导出成 Markdown、纯文本、PDF、Word 或 JSON；「知识库同步」能把资料导出成 Markdown 放进你自己的文件夹。

老版本怎么升级？

在汲作的「设置 → 版本与更新」里检查更新即可，已有资料和生成结果都会保留，升级前会自动备份资料库。
